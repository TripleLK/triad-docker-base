* Reasoning

** Critical Bug Resolution
The primary issue was in the saveSource method using `this.currentFieldId` (always null) instead of `this.currentSourceField.id`. This caused 403 errors because the API received null field IDs. The fix ensures proper field context is maintained throughout the source editing workflow.

** Order Management Enhancement  
When sources were deleted, order numbers had gaps (e.g., 1, 2, 4, 5 after deleting order 3). The enhanced delete method automatically decrements higher order numbers, maintaining clean sequences without manual intervention.

** UI Flow Restoration
The extension's navigation between levels (Sources Manager → Source Editor → XPath Selector) needed proper restoration. Added logic to show the sources manager panel when returning from source editing operations.

** Field Context Display
Added field names to interface elements to improve user experience and reduce confusion about which field is being configured.
