* Reasoning

** Root Cause Analysis
The batch processing system was using this generic prompt:
```
Analyze this equipment data and extract key information about the models and specifications. 
Focus on model names, technical specifications, and key features.

Equipment Data: {{INPUT_JSON_DATA}}

Please provide a structured summary of the equipment information.
```

Instead of the comprehensive AI JSON to Lab Equipment API prompt that:
- Contains detailed processing mode instructions
- Includes metadata preservation requirements
- Specifies exact JSON output format
- Provides comprehensive field mapping guidance

** Solution Architecture
1. **Centralized Prompt Management**: Single source of truth for AI prompt
2. **Fallback Handling**: Graceful degradation if prompt file unavailable
3. **Consistent Usage**: All batch processing utilities use same prompt loading function
4. **Cost Optimization**: Switched to Claude 3 Haiku for better cost/performance ratio
