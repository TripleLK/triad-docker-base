* REASONING

** Model Selection Rationale
Claude 3.5 Sonnet v2 does not support AWS Bedrock batch processing. Research confirmed Claude 3 Sonnet (anthropic.claude-3-sonnet-20240229-v1:0) is the correct model for batch operations. This ensures compatibility and prevents job creation failures.

** Architecture Decision
Moved batch processing functionality from ad-hoc scripts to apps/content_extractor/batch_processing.py for:
- Proper Django integration and import handling
- Reusable internal API for future operations
- Professional code organization and maintenance
- Avoiding module naming conflicts (selectors directory issue)

** Test Data Strategy
Used existing clean source data rather than creating artificial broken records. This approach:
- Tests the fix with realistic data scenarios
- Validates the complete workflow from clean data to processing
- Ensures proper ai_json_record_id assignment and grouping
- Provides comprehensive coverage of both processing modes
