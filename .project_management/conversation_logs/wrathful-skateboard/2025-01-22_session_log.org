** Discussion Summary
User reported InlinePanel KeyError when trying to edit site configurations. The error was `KeyError: 'fields'` occurring in the admin edit/add views. Investigation revealed that InlinePanel doesn't work properly with SnippetViewSet - it's designed for Wagtail Pages, not snippets.

** Changes Made
- Fixed `apps/xpath_content_extraction/wagtail_hooks.py` lines 53-65
- Removed InlinePanel('fields') from SiteConfigurationViewSet panels
- Simplified to basic FieldPanel structure that works with SnippetViewSet
- Also fixed FieldConfigurationViewSet by removing InlinePanel('sources')
- Used MultiFieldPanel with FieldPanel components only

** Rationale
InlinePanel is designed for Wagtail Page models with their complex panel system, but SnippetViewSet uses Django forms underneath. The InlinePanel was trying to access formset relationships that don't exist in the SnippetViewSet context. By using simple FieldPanel components, we maintain Wagtail's built-in admin functionality while avoiding the formset complexity.
