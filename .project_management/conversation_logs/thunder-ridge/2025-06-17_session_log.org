** Discussion Summary
User discovered a critical flaw in the batch processing workflow: models are not being combined correctly. The import command shows "Combined data for [group]: 0 models" consistently, indicating that model batch files are not being identified and combined with overall details files.

** Investigation Results
After thorough investigation, identified root cause:

*** File Structure Discrepancy
1. **Original Two-Mode Exports** (`ai_json_exports/two_mode/`) contain:
   - `_processing_mode: "OVERALL_DETAILS"` or `"MODEL_SUBSET"`
   - `_batch_info` with model relationships
   - `target_model_names` arrays
   - Proper file naming patterns

2. **Batch Processing Converted Files** (`batch_output/json_files/`) contain:
   - NO processing mode indicators
   - NO batch relationship metadata  
   - NO model grouping information
   - Generic `record_N_timestamp.json` naming

*** Conversion Logic Flaw
The `convert_batch_output_to_json_files()` function in `BedrockBatchProcessor` simply converts JSONL lines to individual JSON files, losing all batch relationship context that was present in the original input files.

** Changes Made
- Documented analysis in conversation log
- No code changes made per user request to only analyze and plan

** Rationale
The batch processing workflow breaks the two-mode design because:
1. AWS Bedrock processes each JSON independently
2. AI model outputs don't preserve input metadata like `_processing_mode`
3. Conversion step loses all relationship information
4. Import command can't identify which files are overall vs model data

** Critical Issues Identified
1. **Metadata Loss**: Processing mode and batch info not preserved through AI processing
2. **File Relationship Loss**: No way to link overall details with their corresponding model batches
3. **Import Logic Mismatch**: Current import assumes preserved metadata that doesn't exist
4. **Workflow Design Flaw**: Two-mode export → Batch processing → Import pipeline fundamentally broken

** Next Steps Identified
Comprehensive solution needed addressing:
1. AI prompt modification to include processing mode in output
2. Batch output parsing to reconstruct file relationships
3. Import command enhancement for metadata-less files
4. Alternative workflow design consideration
